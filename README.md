Mapty 🗺️

Mapty is a workout tracking web application where users can log Running or Cycling workouts directly on an interactive map.
Built entirely with Vanilla JavaScript (ES6+), it demonstrates Object-Oriented Programming (OOP), the Geolocation API, and the Leaflet mapping library.

✨ Features

📍 Geolocation Support – Detects your current position and centers the map automatically.

🗺️ Interactive Map – Click anywhere on the map to add a workout marker.

🏃 Workout Types – Record distance, duration, cadence (running) or elevation gain (cycling).

💾 Persistent Data – Saves all workouts in localStorage, so data remains after refresh.

🔄 Dynamic UI – Selecting a workout pans the map to its exact location.

🧩 Clean Architecture – Built using ES6 classes for maintainable and reusable code.

🛠 Tech Stack

Frontend: HTML, CSS, Vanilla JavaScript (ES6 Modules & Classes)

Mapping: Leaflet.js

Browser APIs: Geolocation API, localStorage
